# Bubba Hub WordPress Plugin

Modular rebuild. Development is split into steps so completed features remain stable.

1. Find the right group
2. My Hub
3. Family Planner
4. Book activities
5. Group and class pages
6. Leader Space
7. Get Paid
8. Membership and subscriptions
9. Notifications
10. Family Support
11. Hardening and integrations

Step 1 starts with native WordPress activity discovery. ACF, Ninja Forms, Ultimate Member and GetPaid are treated as integrations rather than hard dependencies.
